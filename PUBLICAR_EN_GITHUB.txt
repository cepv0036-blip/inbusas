Repositorio remoto
==================
https://github.com/cepv0036-blip/inbusas.git

En GitHub el repo puede aparecer vacío hasta el primer push.

Pasos (en una terminal donde exista el comando `git`, por ejemplo Git Bash o PowerShell con Git instalado)

1) Ir a la carpeta del proyecto:
   cd c:\Users\HP\Desktop\servidor

2) Si aún no hay repositorio git:
   git init
   git branch -M main

3) Conectar el remoto (solo la primera vez):
   git remote add origin https://github.com/cepv0036-blip/inbusas.git
   Si ya existía "origin" con otra URL:
   git remote set-url origin https://github.com/cepv0036-blip/inbusas.git

4) Primer envío:
   git add -A
   git commit -m "Initial commit: sitio estático + bot Telegram + workflow"
   git push -u origin main

Si GitHub te pide login, usá un Personal Access Token (classic) con scope "repo" como contraseña, o el cliente GitHub CLI (`gh auth login`).
